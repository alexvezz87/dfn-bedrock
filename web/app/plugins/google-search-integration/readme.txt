Integra la ricerca Google nel tuo sito WordPress con layout personalizzato e controllo dei link esterni.

== Description ==

Google Search Integration è un blocco WordPress personalizzato che ti permette di integrare la ricerca di Google direttamente nelle tue pagine. 

Caratteristiche principali:
- Barra di ricerca Google integrata
- Layout personalizzato per i risultati di ricerca
- Visualizzazione di titolo e descrizione per ogni risultato
- Pulsante per visitare i link esterni con popup di conferma
- Avviso di uscita dal sito per maggiore trasparenza
- Design responsive e accessibile

Il blocco è perfetto per creare pagine di ricerca personalizzate mantenendo il controllo sull'esperienza utente e fornendo trasparenza sui link esterni.

== Installation ==

1. Carica i file del plugin nella directory `/wp-content/plugins/google-search-integration` o installa il plugin tramite la schermata dei plugin di WordPress.
2. Attiva il plugin attraverso la schermata 'Plugin' in WordPress
3. Il blocco "Google Search Integration" sarà disponibile nell'editor Gutenberg nella categoria "Widgets"
4. Aggiungi il blocco alla tua pagina e personalizza le impostazioni secondo le tue necessità

== Frequently Asked Questions ==

= Come funziona la ricerca Google? =

Il blocco utilizza l'API di ricerca personalizzata di Google per recuperare i risultati. I risultati vengono mostrati in un layout WordPress personalizzato invece che sulla pagina di Google.

= Posso personalizzare l'aspetto dei risultati? =

Sì, puoi modificare gli stili CSS del blocco per adattarlo al design del tuo sito. Il blocco utilizza classi CSS standard che possono essere facilmente personalizzate.

= Il popup di uscita è obbligatorio? =

Il popup di conferma appare sempre quando si clicca su un link esterno per garantire trasparenza agli utenti. Questo è importante per l'esperienza utente e la conformità.
